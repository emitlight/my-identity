# 로드맵

원칙: **매 Phase가 끝날 때마다 실제로 쓸 수 있는 상태여야 한다.** 전부 만들고 한 번에 여는 방식은 중간에 동력이 꺼진다.

---

## Phase 1 — 매일 여는 이유 만들기 ★ 최우선

> 목표: **배포된 URL을 폰 홈 화면에 깔고, 매일 아침 푸시를 받는다.**

- [ ] Next.js + Supabase + Vercel 배포 파이프라인 (비공개 레포 → 자동 배포)
- [ ] Google 로그인 + 이메일 화이트리스트 + 전 테이블 RLS
- [ ] **캘린더** — 자연어 한 줄 입력 / 어젠다·주·월 뷰 / 역할별 색
- [ ] **빠른 캡처** — 한 줄 입력 → `inbox`
- [ ] **할 일** — 인박스 · 오늘 · 완료
- [ ] **Today 화면** — 다음 일정 · 오늘 할 일 · 빠른 캡처
- [ ] **PWA + 웹 푸시** — 홈 화면 설치 안내(iOS 필수) · 07:30 아침 브리핑 · 일정 30분 전
- [ ] GitHub Actions 크론 → `/api/cron/tick`

**완료 기준**: 폰에서 일정을 넣고, 다음 날 아침 푸시를 받고, 탭해서 오늘 할 일을 확인한다.

---

## Phase 2 — 자료를 담고 알아서 꺼내기

> 목표: **"대전 맛집" 자료가 대전 가는 날 알아서 올라온다.**

- [ ] **컬렉션 시스템** — 유연 스키마(`schema` jsonb) · 자동 생성 입력 폼·필터
- [ ] 4가지 뷰 — 지도 / 리스트·필터 / 카드 / **매거진**
- [ ] 항목 상세 = 매거진형 페이지 (사진 + 마크다운)
- [ ] **대전 맛집 · 수도권 골프장 실제 투입** (대화로 받은 자료 구조화)
- [ ] **맥락 서피싱 엔진** — 일정 지역 매칭 · 요일 · 미방문 필터 → Today 카드 + 푸시
- [ ] 방문 체크 + 한 줄 평 (알림에서 바로)
- [ ] **메모** — 마크다운 · 한국어 전문검색 · 태그 · 고정
- [ ] **추구미 보드** — 레퍼런스 이미지 + `why` 한 줄 (인테리어·루틴·스타일)
- [ ] **증거 캡처** — 사진 업로드 + `angle_key` + 월간 촬영 요청 푸시

> ⚠️ **증거 캡처를 Phase 3이 아니라 여기 둔 이유**: 성장은 비교 대상이 쌓여야 보인다. 3개월 뒤에 Before/Now를 보려면 **지금부터 찍어야 한다.** 화면(Phase 3)보다 데이터 수집(Phase 2)이 먼저다. 순서를 반대로 하면 화면은 완성됐는데 보여줄 게 없다.

**완료 기준**: 캘린더에 "대전 출장"을 넣으면 그날 아침 맛집 카드가 뜬다. 그리고 매월 1일 "지금 책상 사진 찍어두세요" 알림이 온다.

## Phase 3 — 나를 아는 비서

- [ ] **역할(Role) 시스템** 전면 적용 — 색·필터·집계
- [ ] **습관 트래킹** — 스트릭 · 미체크 알림 · 추구미 연결
- [ ] **성장 일기** — 추구미 타임라인 (레퍼런스 · 증거 · 스트릭 · 마일스톤이 한 줄기로)
- [ ] **Before / Now 비교 뷰** — `angle_key`로 같은 앵글 자동 정렬
- [ ] 루틴 이탈 감지 → **레퍼런스 재노출** ("원래 뭘 원했는지" 다시 보여주기)
- [ ] **회고** — 일간 한 줄 / 주간 리뷰 (역할별 시간 배분 · 목표 진척)
- [ ] **목표 계층** — 연 → 분기 → 월, `metric_logs` 자동 집계 진척도
- [ ] 저녁 회고 푸시 (알림에서 바로 입력)
- [ ] **노션 전체 마이그레이션** (커넥터 연결 후)
- [ ] 주간 자동 백업

## 중간 점검 질문

각 Phase가 끝날 때 스스로에게 묻는다:

1. **이번 주에 이걸 몇 번 열었나?** — 3회 미만이면 기능이 아니라 *동력*을 고쳐야 한다.
2. **알림을 몇 번 눌렀나?** — `notifications.clicked_at` 통계로 확인. 안 누르는 종류는 끈다.
3. **입력하다 포기한 적 있나?** — 있으면 그 화면의 마찰을 먼저 제거한다.

> 기능을 늘리는 것보다 **안 쓰는 이유를 없애는 것**이 항상 우선이다.
