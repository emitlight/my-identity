## 2. 근본 원인 — 왜 하나도 안 움직였나

### 원인 A. 분기/월이 날짜가 아니라 multi-select다 ★

```
분기: ["2분기", "3분기"]        ← 텍스트 태그
월:   ["7월", "8월", "9월"]      ← 텍스트 태그
```

**이것으로는 "오늘이 마감까지 며칠 남았는가"를 계산할 수 없다.** 정렬도, 비교도, 알림도 불가능하다. 그래서 시스템이 *"9월 12일인데 TOPCIT 마감이 9월입니다"* 라고 말할 방법이 아예 없다.

이게 `Not started 17/17`의 직접적이고 기술적인 원인이다.

> **마이그레이션 시 분기/월을 실제 `period_start` / `period_end` 날짜로 변환한다.** 이것만으로 첫날부터 마감 알림이 동작한다.

### 원인 B. 성격이 다른 4가지가 한 DB에 섞여 있다

`category` 값을 보면 이들은 같은 종류가 아니다:

| category | 실제 성격 | 필요한 것 |
|---|---|---|
| `루틴` (비타민, 성경 읽기) | **습관** | 매일 체크박스와 스트릭 |
| `아이템` (attire, cosmetics) | **위시리스트 항목** | 컬렉션과 가격·링크 |
| `위시리스트` (유동현금 5억) | **장기 정량 목표** | 진척 게이지 |
| `여가`·`학습` | **기한 있는 목표** | 마감 카운트다운 |

**습관에 `Status: Not started`를 붙이면 영원히 Not started다.** 비타민을 매일 먹는 것은 "완료"되는 종류의 일이 아니다. 이 불일치 때문에 체크할 곳이 없었고, 체크할 곳이 없으니 안 하게 됐다.

### 원인 C. 실행 단위가 텍스트 필드에 갇혀 있다

```
구체적인 목표:
  - 예산 150만원 이내, 항공·숙소 3월 말까지 확정하기
  - 3일 일정표와 지역 맛집 찾기
```

이건 **할 일 2개**다. 그런데 텍스트 필드 안에 있어서 체크할 수 없고, 마감을 걸 수 없고, "오늘 할 일"에 뜰 수 없다. **텍스트는 실행되지 않는다.**

17개 항목의 `구체적인 목표`에서 이런 실행 단위 **23개**를 추출할 수 있다.

## 5. 이관 방침 (판단)

`DECISIONS.md §5` 에서 "전부 옮기지 않는다"고 판단했었다. 실사 결과 **전부 옮겨도 된다** 로 수정한다.

**이유: 데이터가 17개뿐이다.** 죽은 데이터가 쌓여 있을 거라 예상했지만 실제로는 양이 적고, 전부 아직 유효한 목표다. 선별 기준을 만드는 비용이 그냥 다 옮기는 비용보다 크다.

다만 **형태는 그대로 옮기지 않는다.** 위 매핑대로 4개 테이블로 분해하고, 분기/월을 실제 날짜로 바꾼다. 같은 형태로 옮기면 같은 결과가 나온다.

### 이관 직후 첫 화면에서 보여야 할 것

```
⚠️  기한이 지난 목표 2개
    · Microsoft 자격증 — 7월 마감, 2개월 경과
    · 업계 박람회 네트워킹 — 6월 마감, 4개월 경과
    → 기한을 다시 잡을까요, 접을까요?

🔶  이번 달 마감
    · TOPCIT 900점 — 9월 30일까지 18일
```

노션이 3개월간 하지 않은 말을, 첫 로그인 30초 안에 한다. 이게 증명이다.

## 7. 중복 통합

노션에는 같은 정보가 산문과 목록, 페이지와 DB에 나뉘어 있었다.
**원칙: 한 정보는 한 곳에만 산다. 여러 곳에서 필요하면 FK 로 잇는다.**
두 곳에 두면 한쪽은 반드시 낡고, 어느 쪽이 맞는지 모르게 되면 둘 다 안 보게 된다.

## 8. 아직 결정이 필요한 것 — `옛날 DB`

별도 최상위 페이지 `옛날 DB` 아래에 최소 15페이지가 있다.

```
옛날 DB
├─ About Me ├ 아이템 · short_term_goal · 소비활동(ultimate)
│           └ long_term_plan(+profit) · Brunch Story
├─ Projects · Career · 기타 학습 자료
├─ Certifications › Certification Tracker DB
└─ 2024 하계 일경험 - JIT
```
